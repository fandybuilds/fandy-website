# 🚀 Cosmic Dark Portfolio

Website portofolio personal bertema luar angkasa (*outer space / dark mode*) dengan animasi memukau, navbar melayang berefek *blue glow* (`#2c67ed`), typewriter effect, interaktivitas tab portofolio, dan form kontak yang responsif.

Dibuat menggunakan:
- **React (Vite)**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide Icons**
- **Canvas Confetti**

---

## 🌌 Fitur Utama

1. **Space Theme & Animations**:
   - Background canvas partikel bintang (twinkling stars), shooting stars (meteor), dan nebula glow.
   - Efek glassmorphism dan border neon biru kosmik `#2c67ed`.
2. **Floating Glowing Navbar**:
   - Navbar melayang di tengah atas dengan efek blur dan blue glow.
   - Menu drawer responsif untuk perangkat mobile.
3. **Hero Section**:
   - Teks besar interaktif dengan animasi **Typewriter** yang mengetik otomatis bergantian (*Junior Developer*, *Tech Enthusiast*, *Frontend Specialist*, dll).
   - Tombol Call-to-Action (CTA) dengan efek hover neon.
4. **About Me Section**:
   - Avatar foto profil berbingkai aura kosmik.
   - Statistik interaktif (Total Project, Sertifikasi, Tech Stack, Jam Koding).
   - Tab Timeline Riwayat Pendidikan & Pengalaman.
5. **Portfolio Section (3-in-1 Animated Tabs)**:
   - **Projects**: Filter kategori (Full Stack, Frontend, dll) dengan kartu interaktif, link GitHub, Live Demo, serta Modal Detail Popup.
   - **Certificates**: Kartu sertifikasi industri dengan ID kredensial & tautan verifikasi.
   - **Tech Stack**: Kategori Frontend, Backend, Tools & DevOps dengan indikator level keahlian.
6. **Contact & Socials**:
   - Form transmisi pesan interaktif dengan efek perayaan *cosmic confetti* saat berhasil terkirim.
   - Tombol salin email satu-klik dan kartu sosial media (GitHub, LinkedIn, Instagram, Email).
7. **Footer**:
   - Tombol *Back to Top* halus.

---

## 🛠️ Cara Menjalankan

1. **Jalankan Development Server**:
   ```bash
   npm run dev
   ```
   Buka browser pada alamat yang muncul (biasanya `http://localhost:5173`).

2. **Build untuk Production**:
   ```bash
   npm run build
   ```

---

## 📝 Kustomisasi Data Portofolio

Semua data diri, riwayat pendidikan, pengalaman, proyek, sertifikat, dan tautan sosial media dapat disesuaikan dengan sangat mudah di file:
👉 `src/data/portfolioData.js`
